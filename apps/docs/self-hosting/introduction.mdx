Huddle is 100% open-source and available under the [GNU Affero General Public License v3.0 (AGPL-3.0)](https://github.com/areal/huddle/blob/main/LICENSE)
which allows you to run your own instance of Huddle for free for both personal and commercial use.

## Official Docker Image

The best way to self-host Huddle is using the [official Docker image](https://hub.docker.com/r/areal/huddle).
This image contains a build that is specifically intended for self-hosting.
It is updated regularly but it is _not_ guaranteed to be up-to-date with the latest version of Huddle.
If you want to have access to the latest features and bug fixes, you should consider using the [official managed service](https://huddle.dev).

<Note>
  Though it is technically possible to build and run Huddle from its
  [source-code](https://github.com/areal/huddle), it is not recommended and
  we do not provide support for this.
</Note>

## Live Demo

If you want to try out Huddle before self-hosting it, you can try the official managed service at [app.huddle.dev](https://app.huddle.dev).
This version differs slightly from the self-hosted version in that it allows guest users to create polls without having to create an account
and is updated more frequently but it's still a good way to get a feel for the app.

## Pricing

Huddle is **completely free** to self-host but for users who wish to contribute to the project,
please check out the [pricing](/self-hosting/pricing) page.

## Get Started

Depending on how comfortable you are with technical things, you can either run Huddle on your own server or choose a managed hosting provider that will do it for you.
